# State of GRASS 2026

reveal.js deck for the State of GRASS talk, FOSS4G North America 2026, Sacramento.
Converted from the Claude Design export (`State of GRASS 2026.dc.html`).

## Run

```sh
npm install
npm start
```

Opens http://127.0.0.1:8000 in the browser. Keys: arrows to navigate, `S` for the
speaker view with notes and timer, `F` fullscreen, `O` overview, `Esc` to exit.

## Export to PDF

Open http://127.0.0.1:8000/?print-pdf in Chrome and print to PDF with
landscape orientation, no margins, and background graphics enabled.

## Layout

- `slides/` is the source of truth: one HTML file per slide, ordered by the numeric
  prefix (`010-title.html`, `020-corey-t-white.html`, ...). Pick an unused number to
  insert a slide. Each file is one `<section id="...">` holding a 1920x1080
  `div.slide` with inline styles and an optional `aside.notes` for speaker notes.
- `index.html` is generated by `npm run build` (`tools/build.py`), which wraps the
  slides in `tools/template.html`. `npm start` builds first. Do not edit `index.html`
  by hand.
- `tools/template.html` is the page shell and reveal.js configuration (1920x1080,
  fade transition, notes plugin).
- `theme/grass.css` keeps reveal.js from restyling the inline-styled slides and
  styles the image slots. `theme/ds/` holds the GRASS design system tokens and the
  self-hosted Sintony fonts. Fira Sans and Fira Mono load from Google Fonts, so
  presenting offline falls back to the system sans-serif.
- `assets/` holds images; `assets/slots/` are the images recovered from the original
  Claude Design export.
- `OUTLINE.md` is the talk outline from the design session.

The deck was first converted from a Claude Design export; that converter has been
retired now that `slides/` is edited directly.
